<div>Android application for monitoring and analyzing device usage statistics.
The application collects information about app usage and helps users track their screen time. 
It also demonstrates working with background tasks, notifications, and scheduled events. 
Say something about your usage time.</div>

<h2>🛠 Tech Stack</h2>

<div>Java</div>
<div>MVVM - application architecture</div>
<div>Clean Architecture - separation of presentation, domain, and data layers.</div>
<div>Dagger - Dependency Injection</div>
<div>UsageStatsManager - collecting application usage statistics</div>
<div>Notification - user notifications</div>
<div>AlarmManager - scheduling background events</div>

<h2>🏗 Architecture</h2>

<div>The project follows Clean Architecture + MVVM principles:</div>

<div>Presentation - UI and ViewModels.</div>
<div>Domain - business logic and use cases.</div>
<div>Data - data sources and repositories.</div>
<div>Dependency injection is implemented using Dagger.</div>
